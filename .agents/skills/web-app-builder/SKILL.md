# Modern Web App Builder

## Core Principles
1. **Component Modularity**: Build focused, reusable components with clean prop interfaces.
2. **State & Performance**:
   - Keep high-frequency animation state in refs or GSAP timelines.
   - Use React 18 hooks (`useMemo`, `useCallback`, `useTransition`) appropriately.
3. **Responsive Architecture**:
   - Mobile-first layouts with smooth auto-fit grids.
   - Graceful touch interaction fallbacks for hover-heavy desktop effects.
4. **Clean Routing**:
   - Multi-page client-side routing with `react-router-dom`.
   - Scroll-to-top on route navigation.
